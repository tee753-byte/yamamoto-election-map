本資料は、山本ゆうへい BASE のポスティングマップと、実装元の現行機能を比較したものです。
ミッション、経験値（XP）など action-board 全体に依存する機能は、陣営内の実務には不要なため移植対象から外します。

## 結論

BASEには、区域表示、状態管理、担当割当、配布部数の加算、進捗集計という主要な実務機能があります。
一方、本家にある地図上での区域作成、現在地表示、縮尺に応じた集約表示などは未実装です。
そのため「本家の機能をすべて実装済み」ではありません。

ただし、BASEには本家にない活動期間の制御、自由入力の担当名、同時更新検知、二重加算防止、操作履歴があります。
本家をそのまま複製するのではなく、福津市での少人数運用に必要な差分だけを優先して追加する方針が適切です。

## 改善の推奨順

### 優先度1: 実運用に必要

1. 管理者用の区域登録・編集・削除
2. GeoJSONまたはCSVによる区域の一括登録
3. 目標部数とメモの編集画面
4. 担当区域だけを表示する絞り込み
5. 現在地表示

自由描画だけにすると境界の精度が人によってばらつくため、福津市の町丁目など既存の境界データを一括登録し、必要時だけ管理者が補正できる設計を推奨します。

### 優先度2: 区域数が増えたときに有効

1. 縮尺に応じたマーカー集約
2. 地図上の配布枚数ラベル
3. 区域名・担当者による検索
4. 活動計画の選択・過去データ表示

### 移植しない機能

- action-boardのミッション達成
- XP付与
- ランキング
- action-board固有の投稿・実績画面との連携

これらはポスティング地図そのものではなく、action-boardプラットフォームの参加促進機能であり、少人数の内部運用には不要です。

## 次の実装候補

最初の改善は「管理者が配布区域・目標部数・メモを登録編集できる画面」と「現在地表示」をまとめて実装するのが適切です。
実データの形式が未確定でも、GeoJSONを正式入力、CSVを補助入力とする構造なら後から差し替えられます。
