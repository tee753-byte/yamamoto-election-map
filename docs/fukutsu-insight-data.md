# 福津インサイトのデータ出典と更新方針

最終確認日：2026年11月25日

## 概要

福津インサイトは、福津市とe-Statが公開する人口・世帯・地理データを可視化する。
個人宅、支持者、住民の反応などの個人情報は使用しない。

## 使用データ

### 福津市 人口統計（公称町・大字等別）

- 公開元：福津市 市民生活部市民課／BODIKオープンデータカタログ
- URL：<https://data.bodik.jp/dataset/402249_0000200_00001>
- 利用条件：CC BY 4.0
- 基準日：2026年11月1日
- 加工：1歳刻み人口から年少・生産年齢・老年人口、10歳刻み人口を集計

### 福津市公式・市全体人口

- 公開元：福津市
- URL：<https://www.city.fukutsu.lg.jp/shisei/tokei/4526.html>
- 基準日：2026年10月31日
- 注意：地域別統計とは基準日・集計処理が異なるため、数値を推測で統合しない

### 令和2年国勢調査 小地域統計・町丁字等境界

- 公開元：総務省統計局・e-Stat
- URL：<https://www.e-stat.go.jp/gis/statmap-search>
- 利用条件：e-Stat利用規約（政府標準利用規約第2.0版準拠）
- 基準日：2020年10月1日
- 加工：ShapefileをGeoJSONへ変換し、同じ小地域コードの人口・世帯・年齢統計を結合
- 注意：109境界中101形状を統計へ結合できた。残りは推測せず「データなし」とする

## 更新方法

加工済みデータは `src/features/fukutsu-insight/data` に保存する。
更新時は、独立プロジェクト `fukutsu-insight` の取得・加工スクリプトで原資料を検証し、
次の3ファイルを置き換える。

- `statistics.json`
- `census-2020.json`
- `boundaries.json`

置換後は基準日・件数・出典を確認し、lint、型チェック、テスト、ビルドを実行する。

## 認証と配信

画面とデータ取得APIはBASEのログインを必要とする。Supabaseへ統計データは保存せず、
更新時に検証した静的データをサーバーから配信する。
