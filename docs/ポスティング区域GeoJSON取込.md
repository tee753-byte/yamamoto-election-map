# ポスティング区域のGeoJSON取り込み

管理者はポスティングマップの「GeoJSON取込」から、最大200区域を一括登録できます。
GeoJSONは、地図上の点と点を結んだ区域をファイルにまとめた形式です。

## 必須項目

- ファイル全体: `FeatureCollection`
- 各区域の形: `Polygon`
- `properties.areaCode`: 重複しない区域番号
- `properties.name`: 画面に表示する区域名

任意で `targetCount`（目標部数）と `note`（メモ）も指定できます。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "areaCode": "A-01",
        "name": "区域名を入力",
        "targetCount": 500,
        "note": "個人情報を含まない注意事項"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [
            [130.4800, 33.7600],
            [130.4810, 33.7600],
            [130.4810, 33.7610],
            [130.4800, 33.7600]
          ]
        ]
      }
    }
  ]
}
```

最初と最後の座標は同じ値にして、区域を閉じる必要があります。ファイル内に不正な区域や
重複した区域番号が1件でもある場合は、全件を登録せずエラーにします。既存の配布数・担当・
進捗は変更しません。

町丁目境界をそのまま配布区域にするとは限らないため、正式な区割りがない状態で福津市全域を
一括登録しないでください。現在の実作業に合わせ、地図上で区域を作るか、陣営で確定した区域
ファイルだけを取り込みます。
