# 山本ゆうへい選挙活動マップ 共有用前提メモ

- 更新日: 2026-11-22
- 用途: ChatGPT、Muse、その他の支援AIへ、この企画の前提を短く共有する
- 状態: ローカルMVP実装・検証済み。クラウド・GitHub・本番は未着手（2026-11-23更新）

## 企画の目的

2026年12月27日執行予定の福津市議会議員一般選挙で、山本ゆうへい陣営が内部利用する
スマートフォン向けWebアプリを作る。

機能は次の2つ。

1. 選挙運動用ポスターの掲示場を地図で管理するポスターマップ
2. 告示前に行う想定のポスティング作業を区域単位で管理するポスティングマップ

実装元は `team-mirai-volunteer/action-board`。`mirai-gikai-fukutsu` とは完全に別プロジェクトで、
コード、データ、素材、ブランド、リンクを混ぜない。

## 選挙日程

- 告示日: 2026年12月20日
- 投票日: 2026年12月27日
- ポスター掲示作業は、立候補届出が受理された後の選挙運動期間に行う想定

## ポスター掲示場データ

福津市では立候補予定者説明会が2026年11月2日に開催済み。
欠席者にも、事前連絡のうえ福津市選挙管理委員会事務局で資料が配付される。

次に確認すること:

1. 山本さんが受け取った説明会資料に、ポスター掲示場番号一覧・位置図があるか。
2. なければ、陣営から福津市選挙管理委員会へ今の時点で入手できるか問い合わせる。

公開ページ上では、掲示場一覧・位置図そのものは確認できていない。

実運用に最低限必要なのは「掲示場番号一覧」と「各掲示場の場所が分かる資料」の2点。
住所一覧、目印入り一覧、位置図、紙、PDFのいずれでもよく、緯度経度やCSVは開発側で作成できる。
候補者ごとの掲示区画番号は後から共通設定できるため、実装開始条件ではない。

## ポスター作業の体制

山本さんの話として、現福津市議会議員の石田まなみさんと合同でポスター貼りを行う可能性が
あると聞いた段階。合同作業は未確定であり、決定事項ではない。

未確認事項:

- 掲示場を個人ごとに割り当てるのか、複数人のチームで回るのか
- アプリ上の担当表示を「個人」「チーム」のどちらにするか

この点が未確定でも、複数ユーザー対応のアプリ実装は開始できる。

## ポスティングについて

- ポスターマップとは独立した機能。
- 配布区域は山本ゆうへい陣営が後から決める運用事項で、実装開始条件ではない。
- 区域は管理者が地図上で作成・編集できる設計にする。
- 現時点の想定は、歩いて各戸の郵便受けへ投函する方法。
- 陣営の想定では、告示日の2026年12月20日より前に配り終える。

注意:

「告示日前なら何でも投函できる」という意味ではない。
告示前に配る文書が通常の政治活動文書の範囲か、事前運動に当たらないかは別途確認する。
アプリ自身は法的判断をせず、管理者が決めた活動名、開始日、終了日を記録し、期間外の更新を止めるだけとする。

## システムの前提

- Next.js、TypeScript、Supabase
- スマートフォン最優先
- 管理者、作業担当者、閲覧のみの3権限
- 非ログイン利用者は内部データを閲覧できない
- 個人宅位置、支持者情報、住民の反応は収集しない
- 実データ受領までは架空データを使う
- テーマ主色は山本ゆうへいの確定色 `#620000`
- GitHubへのpush、本番公開、有料契約は事前承諾なしに行わない

## Supabase無料プラン

- 無料プランは、所有者・管理者として関わる全組織を通算して、稼働中の無料プロジェクト2個まで。
- 「みらい議会福津」が唯一の1個なら、この活動マップを2個目として無料で作成できる。
- 開発中はSupabase Localを使うため、クラウド枠を消費しない。
- 本アプリの想定規模なら、無料枠のDB 500MB、ファイル1GB、月間利用者50,000人で十分な見込み。
- 約7日間利用が少ないと休止の可能性があり、自動バックアップもない。選挙運用時は毎日の手動バックアップと予備の一覧を用意する。
- 現段階で有料契約は不要。共有テスト後に必要性を再判断する。

## 現時点の実現性判断

技術的には実現可能。

実装開始を止める未確定事項はない。サンプルデータで開発しながら、ポスター掲示場資料を並行して確認する。
実運用上の最大の依存は、正式な掲示場番号・位置資料を選挙前に入手してCSV等へ整形できることである。
